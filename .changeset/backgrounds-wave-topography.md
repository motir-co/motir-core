The Wave and Topography backgrounds are drawn, each redrawn for every registered style from one per-style table that falls back to the base style's entry. Warm Editorial's Wave is motir.co's hero wave line for line (the 47 lines gathered around the focus element, their drift, glow, touches and squares), so swapping a hand-written hero wave for `<Background id="wave">` changes nothing on screen. Topography draws contour lines over a slowly shifting height map. Every style's `docs/styles/<id>.md` gains a section for each (MOTIR-11606, MOTIR-11617).
