Platform admin console — Provider capacity

MOTIR-9607 · story MOTIR-9539. One new Operations page, /admin/capacity, where platform staff read each provider model’s usage against its limits — planning and agent lanes summed for the state, shown apart as figures — edit a model’s limits, planning share and tier note (operator and above), and set the alert share. Composes console.mock.html’s shell. Gates the capacity screen card.

1 · Loaded, live — a superadmin inside the shell. The ACCESS PATH is the new Provider capacity row (lucide Gauge) in the rail’s Operations group, directly after Monitoring and Fleet settings. Raised-alerts banner (core raised-alert state) · Alert-share card (core alert share, 80 %) · one Provider group per entries[].provider · a Model entry per entry · a Limit row per unit whose limits.<u>.status is set or unknown, judged on lanes.planning + lanes.agent · the 429 row from rate_limited_429 · the not-enforced fold from status = not_applicable (open on the first entry).
