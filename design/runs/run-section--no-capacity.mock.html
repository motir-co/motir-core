Run hosted — a model with no agent-run capacity

A delta on the Run hosted model picker. A model that has no agent-run capacity right now is labelled in the menu and cannot be picked; a selected one holds Run with a line; a launch refused for that reason says so and names the model. Only the start bar’s Run option, its picker and the door’s notices are drawn, plus the Continue and Fix doors that share the picker; the rest of the Run section and the item page are unchanged.

It amends run-section--from-difficulty.mock.html and the published Run hosted design (run-section--hosted.mock.html). Copy for every string, in English and Simplified Chinese, is in design-notes.md.

Panel N1 · The menu, mixed — one model is held

The project overrides High to claude-opus-5, so that option carries the difficulty line as its description; claude-opus-5-5 keeps its shipped Default · anthropic secondary. claude-fable-5-1 has no agent-run capacity right now, so it is a Held model option: the Combobox disabled option (focusable, aria-disabled, label in --el-text-secondary, no dim), the No-capacity tag in trailing, and the Capacity reason line as its description. Its provider secondary is dropped while it is held; it comes back with the label.

Panel N4 · The label clears while the menu is open — before, then after

The verdict is re-read while the door is open. When claude-opus-5-5 has capacity again, the row changes in place: the tag goes, the option stops being aria-disabled, the reason line gives its description slot back to the difficulty line, Default · anthropic returns, the Held Run line goes and Run turns on. No spinner, no skeleton, no dim, and the menu neither closes nor moves its active row: the refresh is silent, so the shell’s navigation-pending grammar does not apply. The reverse change (capacity lost while open) is the same swap the other way.

Panel N6 · Run was refused for no capacity — the No-capacity refusal

The picker was stale: claude-opus-5-5 read available, the person pressed Run, and the launch was refused because it had no agent-run capacity by then. The No-capacity refusal is a sibling of the shipped refusals (Not started — … Nothing was booted and nothing was charged.), in the same Notice under the start bar. Like is no longer offered, the answer refreshes the picker in place, so the option now reads held and Run is off; the Held Run line is not drawn while the refusal stands, so the model is named once. Picking another model clears the refusal. No numbers, ever.
