Panel 14 — Index · each lookup answer and the page that answers it

Total over the lookup’s answers. The forwarded case draws no page: the visitor meets the site itself. Every page is no-store and noindex, nofollow.

Answer Page Status
application, a target the edge can present none — the request is forwarded; the document ends here the target’s
application, credential aws_sigv4 Unavailable page (panels 7–9) 503
application, no target, or a non-https: origin Not-found page (panels 10–12) 404
no_application No-application page (panels 1–3) 200
members_only_application, opensAt set Members-only page, with address (panels 4, 6) 200
members_only_application, opensAt null Members-only page, without address (panel 5) 200
404 from the lookup, for any reason Not-found page (panels 10–12) 404
